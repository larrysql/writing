# 个人世界模型理论框架 V0.2

**Personal World Model（PWM）**

**副标题：概念边界、动态机制与可证伪假设**

版本：V0.2  
性质：探索性理论框架 / 可检验研究纲领  
前序版本：V0.1  
研究方向：认知科学、心理学、人工智能与个人长期决策

---

# 摘要

个人世界模型（Personal World Model，PWM）旨在研究一个人如何将过去的经验转化为对自我和世界的预测，这些预测如何影响行动选择，以及行动所产生的新经验如何反过来维持或修正原有模型。

V0.1 提出了个人世界模型的基本定义、五个内容维度及其可能的运行循环。V0.2 进一步将研究重点从模型包含什么，转向模型如何运行。

本版本提出三个核心观点。

第一，个人世界模型不仅包含关于自我和世界的判断，还包含这些判断与情境、价值评价、行动预期之间的关系。孤立的信念不足以解释长期行为，必须研究它在具体情境中如何参与决策。

第二，模型与经验之间存在双向关系。过去的经验影响模型，而模型又通过注意和行动选择，影响个体未来能够接触到哪些经验。因此，模型不仅从环境中学习，也可能通过选择性接触环境，间接改变自身的学习条件。

第三，模型更新不是新信息进入之后必然发生的结果。信息是否被注意、如何被解释、反馈是否可信、旧判断具有多大稳定性，以及新行为是否能够持续，都会影响更新过程。

在此基础上，V0.2 提出一个最小动态模型、一组可以被操作化的研究假设，以及用于评价理论增量价值的研究路径。

本版本不主张 PWM 已经构成独立、经过验证的心理学理论，而是尝试建立一个能够接受经验检验的研究框架。

# 第一章：理论边界——PWM 究竟研究什么？

## 1.1 从解释人生转向解释具体机制

我们经常用性格、能力、家庭环境和个人选择解释人生差异。

但这些解释之间仍然存在一个值得研究的过程：一个人如何根据自己对现实的理解，形成行动预期，并在不断行动中积累新的经验。

假设一个人长期认为自己不适合创业。

这种判断可能来自缺乏商业经验、曾经遭遇失败、家庭经济责任，或者对创业风险的观察。

当他遇到新的商业机会时，这个判断可能影响他对机会的评估。他可能首先关注失败概率，而较少考虑通过小规模实验验证市场需求的可能。

如果他因此始终回避商业实践，就可能长期缺少能够检验自身商业能力的直接经验。

十年之后，他仍然认为自己不适合创业。

我们可以将这个过程理解为一个由判断、行动和经验组成的循环。

这里真正需要解释的，不是这个人为什么没有创业，而是：

**为什么一个关于自身能力的判断，能够在长期缺少充分检验的情况下，持续影响行动，并通过行动维持自身？**

这类问题构成 PWM 的主要研究对象。

## 1.2 PWM 的工作定义

V0.2 将个人世界模型定义为：

**个体在长期环境互动中形成的、包含自我与环境表征、条件性预测、价值评价及行动预期的动态内部模型。该模型参与调节个体对情境的解释和行动选择，而行动又改变其后续经验的分布，使模型在持续反馈中得到维持、修正或重组。**

相较于 V0.1，这一定义增加了两个关键要素。

首先，模型不只是关于世界的知识，还包含“在某种情境下，如果采取某种行动，可能产生什么结果”的条件性预测。

其次，模型更新所依赖的经验并不是完全随机到来的。个人采取什么行动、进入什么环境、回避什么情境，会影响他能够获得什么证据。

因此，PWM 关注的不只是经验如何改变认知，还关注认知如何通过行动改变未来经验。

## 1.3 PWM 不是什么？

为了防止理论范围无限扩张，需要明确四条边界。

PWM 不是完整的人格理论。它不试图用一个模型解释人的全部性格、气质、情绪和行为差异。

PWM 不是对大脑神经结构的直接描述。我们提出的模型维度和计算变量，是理论分析工具，不代表大脑中存在一一对应的神经模块。

PWM 不是决定论。个人行为受到身体状态、习惯、环境条件、社会关系、经济资源和偶然事件等多种因素影响，内部模型只是其中一个可能的调节因素。

PWM 也不是积极思维理论。它不预设乐观一定优于悲观，或者冒险一定优于保守。一个有效的模型应当能够帮助个体识别真实风险，而不只是增强行动意愿。

PWM 的研究目标，是理解特定判断如何影响行动与学习，以及这些判断在什么条件下可以被修正。

## 1.4 与已有理论的区别

PWM 与多个成熟理论存在明显重叠。

认知图式理论解释已有经验如何组织信息加工；自我效能感理论研究能力判断如何影响行动；预测加工研究内部预测在认知中的作用；强化学习研究行为如何受到结果反馈的影响；叙事身份理论关注人们如何通过人生故事理解自己。

因此，PWM 的新意不能仅仅来自把这些概念放在同一张图里。

V0.2 暂时将其潜在增量价值限定在一个问题上：

**能否通过联合描述个人的条件性信念、行动选择和后续证据接触，解释或预测长期判断的固化与更新，并获得超过已有单一模型的预测能力？**

这是一项需要验证的研究目标，而不是已经成立的结论。

如果 PWM 不能提供额外的预测能力，也不能产生新的、可检验的干预假设，那么它更适合作为整合性的实践框架，而不应被宣称为独立科学理论。

# 第二章：模型的基本单位——从信念到条件性预测

## 2.1 为什么单独记录信念还不够？

V0.1 将个人世界模型分为自我、外部世界、关系、价值和未来五个维度。

这一划分适合描述模型的内容，但不足以解释模型如何运行。

例如，“我不适合创业”是一项自我判断。

但仅仅知道这个判断，还无法预测一个人是否会创业。

我们还需要知道，他是在什么情境下产生这个判断的，认为创业会带来什么后果，重视哪些结果，拥有多少资源，以及能够采取哪些行动。

一个认为自己不适合创业的人，仍然可能因为失业而尝试创业。另一个认为自己具有商业能力的人，也可能因为家庭责任而选择继续工作。

因此，PWM 的基本研究单位不应只是孤立的信念，而应是一组具有情境和行动指向的关系。

## 2.2 最小分析单元

V0.2 提出一个暂定的最小分析单元：

**情境—信念—预期—价值—行动—反馈。**

它包含六个部分。

**情境（Context）：** 个体当前面对的外部条件，包括机会、限制、社会关系及资源。

**信念（Belief）：** 个体对自身能力、环境规律或他人行为的判断。

**预期（Expectation）：** 个体认为采取某种行动后可能出现的结果。

**价值（Value）：** 个体对不同结果的重要性、收益和代价的评价。

**行动（Action）：** 个体实际采取的行为，包括尝试、维持现状和主动回避。

**反馈（Feedback）：** 行动后获得的新信息、结果及体验。

这六个部分共同构成一个可观察的决策与学习片段。

需要注意，它们并不都是 PWM 内部的组成部分。情境和反馈主要来自个体与环境的互动，行动是模型及其他因素共同作用的结果。将六者放在同一分析单元，是为了研究内部模型与外部经验之间的关系，而不是把整个过程都定义为内部模型。

## 2.3 五维结构的新定位

V0.2 保留五维结构，但调整其理论地位。

五个维度不再被视为模型运行所必需的五个独立模块，而是描述模型内容的五类分析视角。

自我模型涉及能力与身份判断；外部世界模型涉及环境规律和风险预期；关系模型涉及他人及社会互动；价值模型涉及结果评价和目标优先级；未来模型涉及长期可能性与预期。

一项判断可以同时涉及多个维度。

例如，“我年纪太大，已经不适合重新创业”，既涉及自我能力，也涉及对外部机会的判断和未来可能性。

后续研究需要检验五维分类是否能够可靠编码实际材料，是否具有足够的区分效度，以及它是否比更简单的分类方式具有额外价值。

如果研究发现某些维度高度重叠，应当允许合并或重新定义。

# 第三章：核心动态机制——模型如何影响自身的学习条件？

## 3.1 基本运行循环

V0.2 将 PWM 的核心过程描述为：

**内部模型 → 情境预测 → 行动选择 → 经验接触 → 反馈解释 → 模型更新。**

这个过程包含两个相互联系的方向。

第一个方向是经验影响模型。新的事件、行动结果和社会反馈，可能改变个体对世界的判断。

第二个方向是模型影响经验。已有判断影响个体关注哪些信息、选择哪些行动、进入哪些环境，以及回避哪些情境。

第二个方向尤其值得关注。

因为它意味着，一个人的世界模型不仅是过去经验的结果，也可能参与决定未来哪些经验有机会发生。

## 3.2 行动介导的证据选择

假设一个人认为自己不具备商业能力。

当他遇到创业机会时，这项判断可能降低他尝试的意愿。

如果他长期回避商业活动，就可能很少获得关于自身商业能力的直接证据。

与此同时，他可能更容易注意到创业失败的案例，因为这些案例与既有判断一致。

于是，原有判断在缺乏充分检验的情况下持续存在。

这里可能存在两个不同机制。

一是信息选择：个体更容易接触或关注符合已有判断的信息。

二是行动选择：个体通过回避某些行为，减少了获得不同结果的机会。

两者可能相互作用，但不能混为一谈。

PWM 将第二种过程暂时称为**行动介导的证据选择（Action-Mediated Evidence Selection）**。

这一名称用于明确研究对象，并不意味着该机制是此前未被发现的心理现象。它与主动学习、经验采样、回避学习和强化学习中的相关研究具有联系。

本框架希望研究的是：这一机制在个人长期信念固化中究竟具有多大作用。

## 3.3 模型的自我强化

当模型影响行动，而行动又改变证据接触时，可能出现自我强化循环。

例如，一个人相信表达不同意见会破坏关系，于是尽量避免表达不同意见。

由于他很少真正表达不同意见，也就很难获得“表达分歧但关系仍然稳定”的经验。

原有判断因而缺少被修正的机会。

但这里必须区分两种情况。

第一种情况是判断确实符合现实。例如，某个具体环境中表达不同意见可能带来真实惩罚，那么回避行为可能是合理适应。

第二种情况是判断已经过度泛化。例如，个体把过去某段关系中的风险，推广到所有新的关系中。

PWM 重点关注的是第二种情况：**原本具有情境适用性的判断，是否因为行动与证据接触的反馈循环，被长期维持并推广到不再适用的环境。**

## 3.4 预测误差为什么不一定导致更新？

直觉上，如果现实结果与预测不一致，个体就应该修正模型。

但实际情况往往更加复杂。

假设一个人相信别人不会接受自己的不同意见。某次他表达了不同意见，对方却表示理解。

他可能因此修正判断，也可能认为对方只是出于礼貌，或者这次情况比较特殊。

同一个反馈，可能产生不同的解释。

因此，模型更新至少受到以下因素影响：旧判断的稳定程度、反馈的可信度、反馈与旧判断的冲突程度、个体当时的情绪状态，以及是否存在其他解释。

一个重要的研究问题是：**在什么条件下，个体会修正原有判断，而不是重新解释新证据来维持旧判断？**

这需要区分正常的谨慎更新与不合理的信念固化。一次偶然事件本来就不应该轻易推翻长期经验。

因此，PWM 不应把模型稳定性本身视为问题，而应研究模型的稳定程度是否与证据质量及环境变化相匹配。

## 3.5 模型的局部更新与结构性更新

V0.2 暂时区分两类更新。

**局部更新**指某个具体判断发生变化，而其他判断基本保持稳定。

例如，一个人通过经营小项目发现，自己能够完成简单的商业交易，于是把“我完全没有商业能力”修正为“我具备部分商业能力”。

**结构性更新**指多个相互关联的判断发生较大变化，进而影响长期目标或行动策略。

例如，一个人经过数年的学习与实践，不仅改变了对自身能力的认识，还重新评价风险、稳定收入、工作意义与未来生活方式。

最终，他可能重新安排职业方向。

结构性更新不一定来自单次重大事件，也可能是长期小变化积累的结果。

未来需要建立可操作的标准，区分一般信念波动、局部更新和跨维度的稳定变化。

# 第四章：最小动态模型

## 4.1 为什么需要形式化？

如果 PWM 只停留在语言描述层面，它可能解释很多现象，却难以产生精确预测。

因此，V0.2 尝试建立一个最小动态模型。

这个模型不试图模拟完整人格，而只描述某项特定判断如何影响行动，以及行动如何影响后续证据与信念更新。

## 4.2 基本变量

在时间 \(t\)，定义：

- \(M_t\)：个体当前与目标问题相关的内部模型状态。
- \(C_t\)：当前情境，包括外部机会、限制与可用资源。
- \(A_t\)：个体采取的行动。
- \(O_{t+1}\)：行动后观察到的结果。
- \(V_t\)：个体对不同结果的价值评价。
- \(H_t\)：习惯、情绪和其他未被模型充分表示的影响因素。

行动选择可以概念性地表示为：

\[
A_t \sim \pi(A\mid M_t,C_t,V_t,H_t)
\]

其中，\(\pi\) 表示行动选择策略。

这意味着行动并不是由模型单独决定，而是在模型、情境、价值与其他因素共同作用下产生。

环境反馈可以表示为：

\[
O_{t+1}\sim P(O\mid C_t,A_t)
\]

这表明个体观察到什么结果，部分取决于其采取的行动及所处情境。

模型更新则表示为：

\[
M_{t+1}=U(M_t,C_t,A_t,O_{t+1})
\]

其中，\(U\) 是待研究的更新规则。

这些表达式目前只是概念性形式化，并未指定完整的概率分布、参数或估计方法。

## 4.3 最小信念更新示例

为了让模型可以进一步接受检验，可以先选择一个具体判断：

“我能够独立完成一个小型商业项目。”

将该判断表示为一个主观成功概率：

\[
p_t=P(\text{项目成功}\mid \text{当前信息})
\]

假设个体最初认为成功概率较低，因此不愿尝试。

如果他进行了一次低风险实验，并获得明确反馈，便可以根据反馈调整这一概率。

在最简单的形式下，可以写为：

\[
p_{t+1}=p_t+\alpha_t(y_t-p_t)
\]

其中：

- \(p_t\)：更新前的成功概率估计。
- \(y_t\)：本次结果的编码。
- \(\alpha_t\)：学习率，控制新反馈对判断的影响程度。

这里假设 \(y_t\) 被编码为 0 或 1，且每次实验具有足够可比性。

例如，初始估计为 0.2，学习率为 0.3，一次成功反馈对应 \(y_t=1\)，则更新后为：

\[
p_{t+1}=0.2+0.3(1-0.2)=0.44
\]

这只是说明更新规则如何工作，并不意味着真实人的信念会按这个数值变化。

现实中，成功的定义可能不同，实验难度可能不同，学习率也可能随着反馈可信度和情境变化。

因此，后续研究需要比较不同更新规则，而不能预先假定某一种规则正确。

## 4.4 自我强化的形式化

模型影响行动，而行动影响证据获得的概率。

假设个体可以选择尝试或回避。

如果低成功预期显著降低尝试概率，那么个体获得直接反馈的机会也会减少。

因此，即使原有判断并不准确，模型也可能因为缺少新证据而长期保持稳定。

这一过程可以通过比较两种策略进行模拟：

第一种策略根据当前信念选择行动，允许长期回避。

第二种策略在风险可控条件下，保留一定比例的探索行动。

如果第二种策略能够更快识别环境真实规律，就为行动介导的证据选择机制提供了一个可研究的方向。

但这并不意味着探索总是更好。探索具有成本和风险，合理策略必须考虑现实约束。

# 第五章：可证伪假设与研究设计

## 5.1 理论必须能够失败

如果 PWM 能够解释任何结果，它就无法成为具有经验检验意义的理论。

因此，V0.2 要求每一个核心假设同时说明预测结果、测量方式和可能的反证。

以下假设主要用于提出未来研究方案，尚未得到 PWM 专属实证研究支持。

## 5.2 H1：行动介导的证据选择假设

**假设：** 在控制初始信念强度、实际能力与客观机会后，某项负面能力信念会通过降低相关行动的发生频率，减少个体获得直接反馈的机会，从而预测该信念的持续性。

研究设计可以采用纵向记录，测量参与者的能力信念、实际行动、反馈机会及后续信念变化。

如果相关信念并不预测行动选择，或者行动选择不能解释后续信念稳定性，那么这一机制假设将受到削弱。

## 5.3 H2：情境泛化假设

**假设：** 某些在特定环境中形成的判断，可能被推广到结构不同的新环境，进而产生不适应的行为。

例如，个体在高批评环境中形成的“表达分歧会受到惩罚”的判断，可能影响其在更安全环境中的行为。

研究需要比较不同环境下的实际反馈，并测量判断是否随着环境变化而调整。

如果个体能够准确区分情境，或者行为差异主要由现实风险解释，那么不应将其解释为不合理泛化。

## 5.4 H3：行动反馈更新假设

**假设：** 对于某些具体、可检验的能力判断，包含真实行动和明确反馈的干预，相比仅提供同等信息量的文字劝说，可能产生更持久的信念与行为变化。

可以设置行为实验组、信息反馈组和适当的对照组。

主要测量干预前后的信念变化、实际行为，以及数周或数月后的保持程度。

如果行为实验并未带来额外改善，或者改善只体现在短期自我报告中，则假设受到削弱。

## 5.5 H4：跨维度更新假设

**假设：** 在某些长期人生决策中，一个维度的稳定变化，可能预测其他维度随后发生的变化。

例如，商业自我效能感的提高，可能先于未来职业可能性判断的改变。

这一假设需要通过重复测量和时间序列分析进行检验。

如果五维结构无法可靠区分，或者跨维度变化不具有可重复的时间顺序，那么五维动态结构的理论价值将受到质疑。

## 5.6 H5：结构化回顾的增量效应假设

**假设：** 相比普通日记或非结构化反思，将人生事件、判断、行动和反馈建立明确关联的回顾方法，可能提高个体识别不准确判断和重复行为模式的能力。

研究应当采用独立评价指标，避免仅凭参与者觉得自己更了解自己，就认定干预有效。

可以考察判断校准程度、对未来行为的预测准确性，以及在新情境中的实际选择。

如果结构化回顾与普通反思相比没有稳定差异，那么它作为独立方法的价值就需要重新评估。

# 第六章：理论评价与未来研究路径

## 6.1 PWM 应当与哪些模型比较？

为了判断 PWM 是否具有增量价值，未来研究至少需要建立三个比较基线。

**基线一：单一信念模型。** 只使用某项自我效能或能力判断预测行为。

**基线二：情境与资源模型。** 主要根据客观条件、实际能力和外部机会预测行为。

**基线三：已有行为学习模型。** 使用成熟的强化学习、习惯或认知行为框架解释行为变化。

PWM 的候选模型则进一步引入信念、行动、证据接触与长期更新之间的关系。

评价重点不是 PWM 是否能够拟合已有数据，而是它能否在未参与拟合的新数据上，提供稳定且有实际意义的额外预测能力。

还需要控制模型复杂度，避免仅仅因为变量更多就获得更好的拟合结果。

## 6.2 什么结果会削弱 PWM？

至少存在五种值得认真对待的失败情形。

第一，个人信念与后续行动之间的关系，在控制客观条件后显著减弱或消失。

第二，行动介导的证据接触无法解释信念长期稳定性。

第三，五维结构缺乏可重复的区分效度，无法优于更简单的分类方式。

第四，PWM 的动态模型在样本外预测中不优于已有模型。

第五，基于 PWM 的结构化反思方法无法产生优于现有方法的实际效果。

这些结果不一定推翻所有关于内部模型影响行为的观点，但会要求我们修改 PWM 的具体结构、机制或独立理论定位。

## 6.3 从 V0.2 到 V0.3

V0.2 完成后，下一阶段不宜继续无限增加理论概念。

我建议 V0.3 聚焦一个具体、可测量的研究场景：

**一个人如何形成并维持“我不具备某种能力”的判断，以及新的行动反馈能否改变这一判断？**

这个场景可以选择职业技能、公开表达或其他风险较低的能力领域。

研究应当首先明确：

1. 如何测量初始信念及其强度。
2. 如何记录真实行动和回避行为。
3. 如何区分直接反馈与间接信息。
4. 如何判断信念变化是否稳定。
5. 如何与已有理论和干预方法比较。

在此基础上，再决定是否需要开发专门的软件工具。

LifeMap 可以在未来承担记录和辅助反思的角色，但理论研究不应预先假定某个产品能够验证理论。

# 结论：从关于人生的解释，走向可检验的动态模型

个人世界模型 V0.1 提出了一个基本观点：一个人对自我和世界的理解，可能通过长期影响行动选择，参与塑造人生轨迹。

V0.2 进一步提出，理解这一过程的关键，不只是研究一个人相信什么，还要研究这些判断如何影响他能够获得什么经验。

一个人可能因为相信自己没有能力而回避尝试，又因为缺少尝试而长期无法检验原有判断。

在这种情况下，模型与经验之间形成了一个自我维持的循环。

但同样的机制也可能支持改变。

当一个人能够识别旧判断，在现实允许的范围内尝试新的行动，并根据反馈重新评估自己的预期，模型就可能逐渐更新。

因此，PWM 当前最值得检验的核心命题是：

**个人内部模型不仅参与解释过去的经验，还可能通过影响行动与证据接触，改变未来的学习条件，并由此影响长期行为模式。**

这并不意味着个人能够随意改变命运。

它意味着，在现实约束允许的范围内，人的认知、行动和经验之间可能存在一个可以被研究、干预和持续观察的动态过程。

如果这一过程能够被可靠测量，并且 PWM 对它的解释具有超过已有模型的增量价值，那么个人世界模型才有机会从整合性概念框架，逐步发展为具有独立研究意义的理论。

在此之前，它应当保持开放。

允许修正，也允许被证据否定。

因为一套真正有价值的理论，不应该只帮助我们解释已经相信的世界，还应该让我们发现自己可能理解错了什么。

## 参考研究方向

本版本主要建立在以下研究传统之上，后续需开展系统文献综述与实证研究设计。

- Bartlett（1932）：记忆的重建性。
- Bandura（1977）：自我效能感与行为改变。
- Markus（1977）：自我图式与信息加工。
- Markus & Nurius（1986）：可能自我与未来身份。
- McAdams（2001）：叙事身份与人生故事。
- Friston（2010）：自由能原理。
- Clark（2013）：预测加工与行动。
- Wood & Rünger（2016）：习惯的心理机制。

这些研究为 PWM 提供理论资源，但并不直接证明 PWM 的定义、五维结构或具体机制假设。
