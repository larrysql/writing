# 重建自我模型

> 我们如何成为今天的自己，又如何摆脱过去的定义。

## 关于这个系列

我们常说“我就是这样的人”：不擅长表达、不适合冒险、缺少商业头脑，或者必须始终坚强。这些判断可能来自真实经历，却未必能够完整描述今天的自己。

《重建自我模型》尝试追问：一个人如何形成对自己的认识？这些认识如何反过来影响注意、选择与行动？当过去的解释不再准确，我们能否通过观察、检验和新的经验修正它？

本系列结合心理学、认知科学与哲学讨论，以现实故事切入，既重视思想深度，也提供可尝试的自我观察方法。它不承诺“成为任何想成为的人”，也不试图用新的标签取代旧的标签。

**核心主张：重建自我模型，不是寻找一个最终正确的自我定义，而是培养持续修正自我认识的能力。**

## 一套可以尝试的实践方法

系列将逐步介绍一个六步循环，而不是要求读者立刻改变自己：

1. **识别**：写下一个长期影响自己的判断。
2. **溯源**：回顾它来自哪些经历与评价。
3. **区分**：将事实、解释和现实约束分开。
4. **检验**：寻找支持与反驳判断的证据。
5. **实验**：在风险可控的条件下尝试新的行动。
6. **更新**：根据反馈修正判断，保留不确定性。

每篇文章末尾设有简短的 **「一次自我观察」**，帮助读者把阅读转化为具体的反思记录。五卷将分别侧重：经历与判断的关系、核心信念、觉察与松动、行为实验、持续更新。

## 写作与研究原则

- **从真实问题出发**：用生活经历引入问题，不堆砌概念与术语。
- **完整自然的论述**：以段落推进思考，避免碎片化排版和刻意制造金句。
- **区分证据层次**：明确哪些来自已有研究，哪些是跨学科整合，哪些仍是假设。
- **不把自我标签化**：模型是暂时的理解工具，不是对人的最终判决。
- **承认现实约束**：个人困境不都能通过改变认知解决。
- **允许理论被修正**：读者经验和后续研究也可以挑战本系列的观点。

本系列不是心理治疗，也不能替代专业心理健康服务。

## 与 LifeMap 的关系

本系列探讨的是 **为什么以及如何更新自我认识**；[LifeMap](#) 的长期方向则是探索如何在尊重隐私、保留不确定性的前提下，记录人生事件、目标、选择、约束与反思，帮助个人持续回顾自己的变化。

LifeMap 不应替用户判定“你究竟是什么样的人”，而应帮助用户发现：哪些判断有证据，哪些解释可能过时，未来还存在什么可以尝试的可能。

> 理解自己，不是为了被一种解释永久定义。
