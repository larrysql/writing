# 觉醒与结构｜走近中观与唯识

本系列以龙树的中观思想和无著、世亲的唯识思想为主要研究对象，尝试从佛教哲学自身的问题出发，理解缘起、空性、自性、意识与经验的关系。

写作也是学习的过程。每篇文章围绕一个核心问题，结合佛教经典、思想史与现代哲学视角展开讨论。

## 文章目录

01｜龙树为什么认为，我们误解了事物的存在？

02｜如果没有“我”，构成我的那些东西真实存在吗？

03｜如果一切都是空的，痛苦还真实吗？

04｜中观为什么连“空”本身也不允许执著？

05｜世亲为什么开始追问，我们看到的世界究竟是什么？

06｜唯识究竟是什么意思？世界只是意识的幻觉吗？

07｜阿赖耶识：为什么过去的经验会影响现在的我们？

08｜中观与唯识，究竟在争论什么？

---

本系列采用开放式写作计划，后续根据学习进展继续扩展。
